# 浏览器与 TapNow Agent

核验日期：2026-09-17；批量确认、交互恢复和原片下载补充核验于 2026-09-29。以下 UI 经验不是永久接口契约。
上下文输出控制于 2026-09-30 通过现有画布的只读检查核验；会话压缩说明依据 Codex 官方文档，是否可用仍以当前客户端为准。

## 已验证的操作路线

1. 默认在 Codex 内置浏览器定位已知画布 URL，不自动切到 Chrome 或其他外部浏览器。未登录时请用户完成一次登录，实际登录成功后复用；不要反复索要登录或代填凭据。子代理缺少内置浏览器入口时按下述任务面板初始化流程处理。桌面版支持本地文件不代表当前自动化工具已接入桌面窗口。
2. 通过画布 Add → Upload 上传。采用浏览器工具文档支持的 file chooser：先监听事件，点击可见上传项，再传本地绝对路径。多选前核对选择器能力。
3. 等待画布出现文件名和正确缩略图。上传调用返回与实际素材出现可能不同步，超时后先核查，不立即重复上传。
4. 选中素材，使用 Add to Chat 或 Agent 的附件／节点引用。明确哪个是首帧、哪个是尾帧，不仅在文本里写一个浏览器无法读取的本地路径。
5. 向 Agent 说明准确模型名、输入角色、数量、时长、画质、音频与动作提示词。可让它先创建生成确认卡，以便核查。
6. 若 Agent 卡没有目标模型，检查画布节点的完整模型菜单；不能把类似名字当作替代品。
7. 检查配置后执行已获授权的单次生成。检查结果节点可播放，再核验元数据和关键帧。

官方说明：[对话](https://docs.tapnow.ai/zh/docs/agent/chat-with-agent)、[上传](https://docs.tapnow.ai/zh/docs/canvas/upload-files-to-the-canvas)、[生成确认模式](https://docs.tapnow.ai/zh/docs/agent/choose-a-generation-mode)。

## 现场辨认

- Ask 是生成确认模式控件，不能仅凭按钮文字推断它是发送按钮；检查可见图标或 DOM 的语义属性。发消息的箭头与生成确认卡的 Confirm 是不同操作。
- Agent 的语言模型选择器和视频生成模型选择器分别控制两种任务，不能混用。
- 画布缩略图比例、低清视频预览流与原始成片可能不同。使用全屏预览的媒体信息，或成功下载后的实际文件核验。
- 每组操作前获取最新状态；确定且不会使后续目标失效的动作合并执行，组末统一核验。用户同步操作、菜单或节点结构变化时重新定位，不能沿用旧坐标或旧元素索引。

## 批量确认与费用

- 用简短方案名把每条提示词、实际模型、参数、输入角色与结果节点对应起来。相同模型和参数的多个方案可能合并在一张卡内，核对卡内任务数与每段提示词；不同模型的卡可能要在上一张确认后才出现。
- 每次确认后先查已出现的节点与状态。Agent 停止且仍缺方案时，只要求补齐缺项，并明确已提交项不再生成；不能将整份原始需求重新提交。操作完成消息与生成完成分开判断。
- Agent 对目录、别名、Draft／普通版及模式限制的解释不是最终证据。遇到与画布菜单冲突时，直接检查对应节点；不要花多轮对话让 Agent 反复研究同一个冲突，也不要将它的一次能力限制写成模型的永久规格。
- 沿用用户已明确的总预算，不因分批出卡重复询问。预算范围需区分媒体生成与 Agent 对话等其他消耗；若用户给的是整体费用上限，不自行解释为仅生成费。账户总余额变化不能直接归因于某条视频。
- 切换画质、时长或音频后，等参数与报价刷新一致再计算。分清总价与 `/s` 单价，并计入实际时长及任务数量；分批检查已提交估算加待提交报价是否在上限内。卡片无价格时，可在未生成节点配置相同参数查看报价，但不能用另一模式或默认参数的价格代替；无法获得可信费用范围时保留待确认状态。

## 分组执行与节点搜索

### 选择最便宜的有效检查

- 短操作优先 AX：将当前已定位的确定动作和状态核验放在同一调用。已知字段可用 `getAXState({emit: false})` 在工具内读取新状态、断言并返回摘要；工具不支持抑制输出时用其支持的增量观察。首次探索、出现歧义或异常时输出足够定位的新状态。截图后需要再次使用元素编号时，按当前工具文档刷新完整 AX，不复用旧编号。
- 重复操作在工具已暴露 Playwright 时，用 `getByRole`、`getByLabel` 等语义定位重新解析元素；首次从真实 AX／DOM 确认名称、作用域和选项。不要根据记忆编造定位器，不能用 `.first()` 消除同名节点歧义。
- 已知菜单路线可在一次调用内执行“打开 → 读取或断言可见目标 → 选择 → 读取选中值”。遇到未见过的选项或结构就返回新状态；无需为了批处理强行猜下一步。
- 稳定的提示词和表单字段可连续填写，再读取实际值核对。切换模型作为检查边界，先确认重置后的选项；实际模型、参考图角色、数量和报价在提交前检查。
- 正常路径只返回目标字段、选中值、结果摘要或状态差异；不重复打印整页提示词、全量画布和工具文档。状态未变化时不立即重复同一种完整观察。
- 工具已有自动等待时不额外固定 sleep。生成排队期间降低检查频率，优先任务状态；等待长任务按工具支持采用有界等待，避免高频截图。异常后先查原任务，不自动重放整组或重新生成。

### 上下文与图片预算

- 菜单、参数、价格和任务状态优先用 AX／DOM 文本检查；缩略图身份、连线、透视、光照和动作质量需要视觉检查。只返回本次决策所需的字段或图像，避免每次同时输出整页状态与全屏截图。`emit: false` 只抑制本次观察输出，不删除旧消息；提取摘要也不能省略工具要求的新状态检查。
- 截图范围以当前判断需要为准，工具支持时截目标区域；需要周边关系时保留完整视图。已核验的同一图片不重复输出。下载结果先核对文件、尺寸和时长，再按方案制作一张标注清楚的关键帧联系表；细节不清时再查看原帧或播放相关片段。预览副本不替换、不降质上传用的原始首尾帧或交付原片。
- 工具返回大型嵌套结果时先在执行环境内解析，只输出目标字段和有界文本，必要时注明截断；不要打印图片 base64、媒体正文、整份历史或工具清单。按任务读取相关参考段落，不反复加载整个技能目录。
- 长批次的阶段结束或准备压缩时，整理最小续接信息：画布 URL、素材位置及首尾帧角色、方案与实际模型参数、授权数量及预算、已提交任务和当前状态、下一步。默认在对话中简述；确需跨会话恢复时才按工作区约定保存小文件，不写凭证或账号资料。恢复先核对原任务，提交状态不明不重复生成。
- 既有历史的删减由 Codex 客户端管理，不能用提示词、REPL 重置或技能规则声称“只保留最近截图”。当前客户端支持时，可在安全阶段用 `/compact` 压缩历史；需要完全独立的上下文时，用简短续接信息和必要参考图开始新任务。`/fork` 复制历史，不是上下文清理；新建任务须遵守用户授权，不自行创建。
- 自动压缩阈值按 token 计量，不等于图片或请求体的字节上限；提示缓存命中也不能证明传输体积已经减小。不为本技能改动全局模型、连接方式或压缩配置。异常变慢时区分 UI 工具耗时、模型请求等待、连接重试和平台生成排队；有可读日志时核对请求体字节及调用间隔，不能把总耗时全部归因于网速或截图。默认不新增过程日志。

当前控制方式已经过只读核验：在同一次调用内部读取完整 AX、提取目标字段后只输出摘要，未输出截图、未触发生成。该结果证明输出可缩小，不代表既有上下文被清除，也不证明稳定的端到端提速倍数。

会话机制参考：[Codex 命令](https://learn.chatgpt.com/docs/developer-commands)、[配置参考](https://learn.chatgpt.com/docs/config-file/config-reference)。

### 独立上下文子代理

- 为连续操作或大量读图委派一个有界阶段，使用当前委派工具支持的空白历史模式；本环境为 `collaboration.spawn_agent` 的 `fork_turns: "none"`。默认的 `all` 会带入主聊天历史，不能用于隔离旧图。主代理只传任务目标、验收条件、授权数量／预算、画布 URL、必要素材的路径或节点名称及角色、原任务提交状态，不传整份聊天或历次截图。沿用当前模型设置，不为隔离上下文改全局配置。
- 主代理管理用户沟通和最终交付，子代理完成该阶段的浏览器操作或本地视觉检查。只回传结论、实际参数、任务状态和必要证据位置；不把完整 AX、工具文档或每一步截图搬回主聊天。读图结果优先文字摘要，用户验收确需图像时才提供相应图。参考原图保持完整，子代理可先查看派生小预览或联系表；主代理不例行重读所有原图。
- 同一个 TapNow 画布 URL 可用于重新打开已保存的服务端状态，不依赖聊天历史复制。未保存的输入、打开的菜单和当前选择属于页面临时状态，不能当作已完成交接；是否实时同步以页面本次显示为准。开始前保证只有一个代理修改该画布，交接后读取原节点和状态，避免重复提交。
- 空白上下文不保证拥有主任务的内置浏览器入口。先按当前工具文档枚举；缺少入口时，将已知画布用 `open_in_codex` 打开到该子代理任务。返回 `queued` 时，由主代理用 `navigate_to_codex_page` 显示该任务，再让子代理重新枚举、绑定本任务的内置浏览器并核验原节点。只使用实际工具返回或已核实的任务 ID，不复用其他任务的浏览器 ID。此流程已在独立子代理中验证入口出现且语义点击成功；不要把 `queued` 当作已经可控。
- `Browser is not available: iab` 是工具入口失败，不能推断 TapNow 无法共享画布；不靠猜底层 browser ID、登录令牌或私有 API 修复，也不自动回退 Chrome。入口可用后若显示登录页，请用户登录一次并等待；已登录直接核验原画布继续。
- 子代理没有可用浏览器时，保留主代理作为唯一 UI 操作者，将读图、关键帧比较和素材分析交给独立子代理；不反复创建代理或重试相同入口。若需要另建可操作浏览器的本地任务，遵守新任务的用户授权要求。主代理使用前述分组和有界输出，已有历史仍由客户端压缩处理。
- 子代理自己的文字、工具输出和截图也会累积。每个操作子代理通常只处理 1–2 条生成任务或一个上传、配置、提交核对、下载等浏览器阶段；达到约 30 次浏览器工具调用或输入明显变大时，安排最近的安全业务边界交接。此数值是控制阶段长度的经验目标，不能据此中断结果未知的付费请求。只交接最小摘要，下一阶段创建新的空白历史子代理；向旧代理发送后续任务并不会清除其上下文。
- 交接前保存已提交任务的节点身份、实际输入角色、参数、报价和状态；接手先核对服务端节点，不能把复制节点携带的旧视频算作新生成。上传／下载、未保存编辑或提交状态未知时不轮换，不同时操作同一画布，不因换代理增加生成次数。短阶段继续复用当前代理，避免额外启动与协调开销。
- 验证隔离时，区分子代理请求体、主代理请求体和服务端生成等待。可读日志中比较压缩后字节，并核对历史图片是否继承；不要把 token、截图文件大小或日志文件大小当作实际传输量。基础指令和工具文档仍占上下文，委派也有模型开销；没有同任务对照时不宣称固定提速倍数。

参考：[Codex 子代理](https://learn.chatgpt.com/docs/agent-configuration/subagents)。

### 可复用的无生成脚本

[`scripts/search-nodes.js`](../scripts/search-nodes.js) 提供 `searchTapnowNodes(tab, {kind, query})`，在一次调用内打开节点搜索、选择类型、填写检索词并验证最终条件。适用于重复定位素材和生成节点；不点击搜索结果、不编辑节点、不提交生成。

首次使用先读取当前浏览器工具文档，打开一次节点搜索，核实 dialog、textbox、类型筛选的真实角色和名称。脚本中的英文控件名不是永久契约；语言或 UI 改变时只依据新状态适配。已初始化的 `tab` 必须支持脚本使用的 `playwright`、`paste` 与 `getAXState`；没有这些能力就用 AX 分组，不自行另起浏览器驱动。

受控输入框若在 `fill` 后出现残留或输入法组合文本，先检查实际值；可使用已验证的“聚焦输入框 → 全选 → 粘贴文本”，空值用 Backspace 清空。类型切换后的状态检查仍放在同一调用中。此脚本采用该方式，粘贴可能改变浏览器剪贴板；不用粘贴读取或传输无关剪贴板内容。

用文件读取工具读脚本，将函数声明放入当前 `cua_repl` 会话一次，再在后续调用中复用；不要用 shell 执行浏览器交互，也不要假设 REPL 支持文件系统 import。调用形状：

```js
// tab 是当前已绑定画布；query 来自本次用户需求或已观察到的节点名。
nodeRepl.write(await searchTapnowNodes(tab, { kind: "Image", query }));
```

函数内部按顺序执行；最终仅返回类型、检索词、截断标记及有限结果文本。失败抛出错误并停止，不重试点击；检查一次当前 DOM／AX，必要时截图，再从已确认状态恢复。搜索不会选择节点，仍应结合文件名、缩略图和角色确定正确目标。

同样的结构可用于本次已核实的参数控件：语义定位 → 顺序填写 → 一次状态等待 → 读取并比对实际值 → 返回摘要。只把真实重复的操作提取为函数，不搭建通用自动化框架。不要将付费提交藏在配置辅助函数内。

### 验证提速

优化时在同一画布用不生成的操作做前后对照，比较工具往返数、截图数、最终字段与恢复状态。记录结果于对话即可。区分工具调用、底层 UI 动作与模型往返；一次调用包含多个动作，并不表示底层动作只执行一次。单次耗时仅为该次观察，不能换算成稳定倍速或账户额度节省比例。

## 交互与会话恢复

- 新会话重新枚举浏览器和标签页，以用户指定画布 URL 定位；不要保存固定的浏览器 ID、元素序号或屏幕坐标。节点名称结合缩略图及首尾帧引用定位，不能靠同名 Video 节点的顺序。
- 临时标签页的保留标记可能只对当前轮有效。交付时使用当前工具文档的保留方法；下一轮仍先枚举。旧标签句柄失效时恢复已知画布，不重新创建素材或生成任务。
- 页面崩溃与生成失败是两回事。同一已登录浏览器的新标签页可以重开已知画布，先验证原素材、原节点和生成结果仍存在，再继续操作。不要因此新建或重跑任务。
- 按钮点击无效或落到邻项时，先看新状态排除弹层与页面更新；对真实 button／menuitem 可尝试语义定位后 `press('Enter')`，并核对选中值。不要把一次观察到的坐标偏移写成固定补偿值，也不要对提交状态不明的 Confirm 用另一种方式再点一次。
- Agent 富文本输入框可在确认唯一作用域后填写，再按当前界面验证过的发送键提交；Enter 与 Ctrl+Enter 的作用不能凭习惯互换。发送后核对消息确实进入对话。
- 标题点击可能只编辑标题而未选中节点；依据实时 DOM 定位含该名称的节点卡片主体，或使用节点搜索。只读检查当前 DOM 的角色、容器和媒体属性即可，不读取应用隐藏状态。
- 截图、DOM 与点击结果明显不同步时，不连续重试坐标。先确认没有未保存输入或未完成上传，再刷新当前画布，核查服务器已保存的原节点；仍失效才按当前浏览器工具规则恢复标签。不要关闭可能仍在传输素材的旧标签。
- 隐藏 file input 的直接点击可能因不可见失败；改用它对应的可见 Upload 项，仍然走文档支持的 file chooser。
- 上传或下载等待异常长时，先检查 UI 成果与传输状态。未确认结果前，不再触发同样的操作。
- 若下载取消但视频仍能在画布播放，可以交付画布结果并说明尚无本地副本；不要宣称下载成功，也不绕过浏览器去抓取认证数据。

## 原片下载与对比

- 画布小预览和全屏详情中的视频可能是不同清晰度。选中目标节点后，从可见 Full Screen 入口打开详情，先核对标题及模型；使用当前工具提供的媒体信息读取能力，或 DOM 中 video 的 `videoWidth`、`videoHeight`、`duration` 检查原片。不要自行删改预览 URL 的查询参数来猜原片地址。
- 当前工具支持时，可对全屏详情内唯一的 `video` 调用 `downloadMedia()`。该路线已有成功落盘的实测，也有旧会话导航后崩溃的记录，因此以本次结果为准。保存返回路径，检查文件存在、非零、可解码及实际尺寸，再复制到交付目录；方法仅返回或视频仍能播放，都不足以声称已下载。
- 下载按钮使用工具支持的 download 事件时，先监听再触发。事件超时不必然表示下载失败：先查页面反馈、已知下载目录和对应文件，再决定是否换用全屏媒体下载。只重试下载，不重新生成。
- 多方案用相同时间基准抽取关键帧，检查实际首尾帧、动作发生顺序、空间视差、形变、意外开壳／新增物体、叠化或黑场及稳定尾段。提示词写了禁止项不代表成片遵守；缩略图不能代替动作检查，有歧义时播放或加密该段采样。
- 比较时可制作带方案标签的同屏本地预览，保留各条原片和原速；较短视频末尾定格以对齐时长，并说明预览经过拼接。模型和提示词同时改变的测试只能比较方案效果，不能据此断言某模型整体更强。生成质量判断与媒体成功下载、解码分别报告。

## 接口研究结论

已确认 TapNow 域名下存在 OAuth MCP 服务；详细证据见 [连接方案](connection-options.md)。是否可替代浏览器取决于正常授权后实际工具清单，不能由 MCP 存在推断它支持全部画布或视频操作。

[Microsoft Playwright MCP](https://github.com/microsoft/playwright-mcp) 是通用浏览器控制方案，非 TapNow 专用接口。已有浏览器工具能完成任务时，无需为了同一能力另装一套。

[Tapnow-Studio-PP](https://github.com/chapterv/Tapnow-Studio-PP) 是独立自部署画布，不是控制 app.tapnow.ai 现有账户／画布的连接器，不能混为一谈。
