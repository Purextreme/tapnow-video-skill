# 05 复杂画布的排列、移动与归档

**输入**：本次工作节点 ID 集合、需保护的原画布快照、允许修改的范围。
**完成条件**：工作节点可选且不遮挡输入，选区内部与外部没有新增碰撞，原素材身份与连线保留。

1. `readCanvas()` 一次读取公开 DOM 的节点世界坐标、尺寸、标题、媒体身份及边。`collisionPairs` 找碰撞；不把屏幕缩略图混成世界坐标，也不读取 React 私有状态。
2. 默认只整理当前工作集，`selectNodes(ids)` 通过节点的 Enter 入口单选，多选追加用 Shift＋实际命中检查，随后验证完整选区 ID；不要把 Shift+Enter 当成已验证的多选。当前全画布 Ctrl+A 未验证可用，脚本拒绝推定全选；用户已通过当前 UI 选出的完整集合核对一致后可直接排列。全画布整理仍须有范围授权。
3. `arrangeSelected(ids,'Grid Layout')` 或 `'Horizontal Layout'` 调用内置一键排列。排列后运行 `compareCanvas(before,after,ids)`。选区内部整齐仍可能覆盖外部节点；产生外部碰撞时，先 Undo 并核对恢复，再换空区或画布。Snap to Grid 只吸附，不等于一键排列。
4. `planFreeSpace(nodes,ids,{area,...})` 在当前可见世界区域内寻找空位，保留标题与下方编辑栏空间。长距离移动用 `dragSelected` 的当前卡片边缘命中点，复用实测位移增益；增益使终点越界时先清除校准，仍越界则先导航，不发送越界拖动。短距离用 `moveSelected` 的方向键／Shift＋方向键校正，实测步长后有限批发；两者临时关闭吸附并恢复。窗口／缩放变化清除校准，失败先读实际位置，不重放旧位移。
5. 完成区可用 `archiveSelected(ids,'Group')` 或 `'Stack'` 归档。脚本验证新增容器、原 ID 和外部节点／边；Group 另核对原节点身份及位置不变，Stack 按计数与预览资产核对成员。只支持普通图片／视频的单层容器，组和堆叠不能直接套用普通节点移动脚本。需要还原时 Group 用实际 Ungroup 控件，Stack 在明确当前最近操作后对新 pile 节点按 Ctrl+Z，再用 `compareCanvas(before,after,[])` 核对；不连续盲目 Undo。Stack 的隐藏成员可能暂时没有标题／缩略图，先解堆并等待素材恢复后才能作为生成输入。
6. 可见区域没有足够空位，或为下一步需要反复缩放、找节点、拆堆叠时，优先新开生产画布，只复用本次素材。先通过 MCP 获取 Library ID，必要时保存素材到 Library，再用当前页面的 New canvas 入口；不得假设存在“复制整个画布”的 MCP 能力。不要为复用少量素材永久把全部生产任务塞在一张大画布。

**按流程手动整理**：先读节点和边，在本地按“素材→生成→后处理／输出”分区；共享素材集中，反馈／修订支路单列，不强行把有回路的流程拉成直线。标题可重复，计划用 ID 与当次世界坐标表达，不在 Skill 保存项目名称或坐标。`canvas-layout.mjs` 的 `createLayoutRunner({controller,before,plan,...})` 接受 `[{id,x,y}]`，按 ID 分批 `moveNodes(ids)`，先检查计划内部及外部碰撞，再逐节点读回。远处视区用 `controller.panTo(x,y)` 按当前小地图换算，并验证节点未动；遮挡、无位移或视区改变就停下检查。

**可选接口加速**：按[同源接口约定](../observed-api.md)提供 `positionApi` 与 `syncCanvas`，可一次批量写入普通节点的绝对世界坐标，省去逐节点选择、导航和拖动。请求串行、间隔至少 1.5 秒。先回读服务器，再同步页面核验；普通失败只对确认未到目标的节点安全回退，`routes` 返回原因。限流、鉴权异常、写入结果未知或无关变化须停下，不能借续跑转 UI。组、堆叠及其它接口操作不套用这个坐标写入器。

**保护与续跑**：每组变更前后比较节点 ID、标题、连线和允许移动集合。只用节点自身的媒体内容标记核验身份，排除选中编辑器的图标、参考缩略图与 @ 芯片；预览 variant／懒加载不等于素材替换。`onProgress` 返回当次计划、起始时间和已完成 ID；任务内按需保存，续跑传回 `checkpoint` 并重读画布，已到目标的节点不再次拖动，已完成节点漂移则停下。最终核对全工作集碰撞与身份；需要确认保存时刷新一次再读回。Undo 后同样核对。默认不重排全部历史节点，不删除来源不明节点。

**大画布策略**：选择分散节点与处理外部碰撞可能比排列本身更慢。先测工作集，不按总节点数假定必须全选；获准整图整理时按局部视区逐批执行，无需让全图同时可见。先腾出目标区并安排移动顺序，避免后续节点挡住待整理节点；保留标题和展开编辑器空间，不追逐无意义的像素精度。单纯生产任务因遮挡、空区不足而反复导航时，优先紧凑工作区／已核验的组或新画布。选择失败不能拿部分选区继续原请求。
