# 型号识别与参数核对

按用户指定的完整名称选择；以当前 TapNow 节点菜单、任务模式和实际选项为准。本页提供易混项及一手资料，不保留旧版时长、分辨率、参考数量或促销额度作为默认规格。

## 易混型号

| 名称 | 操作时核对 |
| --- | --- |
| Kling 3.0、Kling 3.0 Omni、Kling 3.0 Omni Edit | 分别选择完整名称，不能根据首尾帧任务或相似名称互换普通版、Omni 和 Edit |
| Seedance 2.0、Mini、Fast、2.5 | 后缀和版本分别识别，不继承其他型号的参数或已结束活动的无限额度 |
| MiniMax H3、H3 Max | 分别检查首帧、尾帧、多模态参考和音频入口，不因 Max 后缀假定能力是超集 |
| Gemini Omni 1.1 Flash 及相似名称 | 核对版本和完整后缀，未证实的简称不当作同一型号 |
| HappyHorse 1.0、1.1 | 分别核对编辑及参考模式，不自动继承前一版本的入口 |

Agent 确认卡与画布完整菜单可能列出不同选项，分别核对；DOM 图标标识和宣传徽标都不是永久接口。MCP 的 artistic／draft／fast／quality 等档位只有在实时工具明示映射时，才能报告为具体厂商型号。

## 参数检查项

- 输入用途：文生、首帧、首尾帧、主体／多模态参考或编辑；按槽位确认数量、顺序、来源及连线。
- 输出规格：画质、画幅、分辨率、音频、数量、单次时长和延长总长；区分原生分辨率与超分。
- 更换型号、模式或素材后重查参数与报价。Auto 不等于已手动指定，Standard／Pro 名称也不能直接换算成像素。
- 原生模型能力与 TapNow 的接入能力分开判断；公开资料缺项按当前页面核验，仍未取得的信息标记未验证，不按命名猜测。
