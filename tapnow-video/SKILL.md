# TapNow 图片、视频与画布操作

本技能用于 Codex；Agent 指 TapNow 网页内置助手，子代理指 Codex 子代理。

## 入口与资料

### 五张可复用操作卡

短流程优先 **MCP → DOM／本地脚本 → 图标匹配／模型视觉**。内部接口仅作已验证且收益明显的可选加速，例如批量坐标写入；普通菜单、导航等沿用默认路线。接口失败先读回、再安全回退并报告，限流或鉴权异常停下核验。只加载本次需要的卡片，不逐步上传全量截图：

| 卡片 | 用途 | 主脚本 |
| --- | --- | --- |
| [01 会话与能力路由](references/cards/01-session-routing.md) | MCP 能力、画布身份、收起聊天、计时入口 | preparation.mjs、browser-actions.mjs |
| [02 素材与节点定位](references/cards/02-assets-navigation.md) | 精确搜索、复用、上传、遮挡命中检查 | browser-actions.mjs、upload-files.js |
| [03 图片／视频与模型对比](references/cards/03-video-preparation.md) | 首尾帧、参考图与真实 @ 素材、图片、型号对比 | browser-actions.mjs |
| [04 视频延长与放大](references/cards/04-video-extension.md) | 前补／后续、时长、视频放大草稿 | browser-actions.mjs、match-control.py |
| [05 画布排布管理](references/cards/05-canvas-management.md) | 按流程排布、移动续跑、分组／堆叠与新画布策略 | canvas-layout.mjs、canvas-geometry.mjs、browser-actions.mjs |

共用的加载方式、窗口变化、像素匹配与网络恢复见 [脚本运行约定](references/script-runtime.md)。每次完整准备都返回连续墙钟计时；不得把动作耗时相加冒充总耗时。20 秒是验收目标，失败、冷启动、上传与恢复耗时也须如实区分。

- 优先复用已连接的官方 MCP，按实时工具参数判断能力；项目、素材和结果查询优先走 MCP。精确型号、首尾帧、分辨率或节点编辑未被覆盖时，用浏览器补足。仅需新增或排查连接时读取 [连接方案](references/connection-options.md)。生成工具可能直接付费提交，不能用来创建测试草稿。
- 页面操作建议优先使用已连接的外部浏览器（如 Chrome）；窗口或缩放变化后重读控件位置。未登录时请用户完成一次登录后复用。仅按[可选同源接口](references/observed-api.md)复用当前页面实际请求，不猜路由、不读凭据文件或应用隐藏状态；会话鉴权只在内存中短暂使用，不输出或保存。
- 需要选择或区分型号时读取 [模型对照](references/models.md)；实际可选模式、参数与费用以当前节点和工具参数为准。
- 素材先复用画布／Library。MCP 可接收真实附件或现成 HTTPS 图片时优先使用；本地文件默认交给[网页文件选择器脚本](references/browser-workflow.md#本地上传的分阶段执行)。选择器在交接前受阻时，小文件可按[素材卡](references/cards/02-assets-navigation.md)选用直传。下载先用 MCP 返回的原片地址，脚本点击 Download 兜底。节点配置、查询、恢复和下载按 [浏览器工作流](references/browser-workflow.md) 的相关段落执行。

## 配置与提交

默认先用简短、干净的正面提示词表达主体、动作与必要镜头；效果不理想时才针对实际问题增加约束。默认给一个可直接提交的版本，以自然段为主；复杂素材分工按需分段，保留用户指定格式。

- 保留用户指定的主体数量、结构、动作顺序、空间关系与结束状态；只补必要的可观察细节，不擅加剧情、主体、声音或台词，不堆通用画质词和无关负向词。
- 多素材逐项明确用途；同一产品的多视角共同定义一个实体。参考已清楚表达的动作或运镜，只说明采用范围和必要差异，保留用户节拍，不另编数字时间线。

默认音频、Turbo 关闭、1 份输出；当前型号没有音频开关时标明未暴露，不能据此保证成片无音轨。Reference 通过真实 `@素材` 芯片引用已绑定节点，不用纯文本冒充。

1. 定位原画布、素材和节点，明确每个输入的用途与首尾帧顺序。完整匹配用户指定型号，保留 Omni、Fast、Mini、Pro、Edit 等后缀；MCP 的档位名称不等于具体型号，提示词不能替代实际参数。
2. 先绑定输入，再配置画质、画幅、时长、音频、数量等参数。时长按当前型号、模式及已绑定输入支持的范围、档位或步长，结合任务需要选择；目标短于模型最小时长时，按下方“目标短于最小时长”适配，不固定为 4 秒。更换型号、模式或素材后重新核对；检查实际槽位和缩略图，不能只凭 Frames、Auto 或菜单徽标判断配置。
3. 使用页面 Agent 建任务前确认处于 Ask／手动确认模式，无法确认时直接操作画布。核对确认卡及实际节点；Agent 对型号或能力的解释不能代替页面证据。
4. 提交前核对型号、提示词、输入角色、参数、数量、报价和授权预算；仅 Frames 模式且实际绑定首帧、尾帧的任务须通过[Frames 首尾帧风险审核](references/frames-risk.md)，触发时先暂停并取得风险确认；Reference 模式不套用此项。仅配置或定位测试停在提交前；配置辅助函数不包含 Generate、Confirm 或 Agent Send。
5. 每个任务只提交一次。状态未知时先查原节点和任务，不重复点击或换入口提交；排队和运行中继续查询，明确失败后才按授权判断重试。分批确认及费用见 [批量确认与费用](references/browser-workflow.md#批量确认与费用)。

## 目标短于最小时长

- 区分目标有效片段时长、参考时长和模型提交时长，按当前型号、模式及输入核验实际限制。目标短于输出下限时，自动选择当前最小可用时长提交并简述适配，不以用户明确要求“最短”为前提，也不把 4 秒当作通用下限。
- 保留所需动作、镜头与节奏，按意图选择动作完成后尾帧保持，或自然收束、延续镜头填满剩余时长，不新增关键事件或循环填时。需要完整继承参考路径且允许改变速度时，可将参考等比减速至提交时长，保留原件并说明速度变化；仅在速度、结局或关键节拍存在无法判断的冲突时询问。
- 严格短时长交付需后期裁切或定帧，保留生成原片并核验动作完成时点、结尾状态及实际时长；不能把按模型下限生成的较长文件直接当作目标时长成片。

## 执行与验证

- 固定流程优先复用上述卡片与脚本，在同一 CUA 调用中执行整组动作并核验结果。菜单和参数用实时语义控件，素材身份、输入角色、连线和成片效果仍要核对。仅在新控件、真实歧义或验证失败时调用模型视觉；固定图标先用本地特征匹配，不默认 OCR。无法脚本定位时再按 [OCR 定位与点击闭环](references/browser-workflow.md#ocr-定位与点击闭环) 处理。浮动参数入口以 Enter 打开，再用同一入口关闭；Escape 可能清空节点选择。
- 提交成功不等于生成完成。按 [生成、查询与网页验收](references/browser-workflow.md#生成查询与网页验收) 核对原任务、实际媒体及播放状态；恢复时沿用原画布和节点。选错型号应如实报告并保留结果。
- 长任务只返回必要字段和图像，在安全阶段保留最小续接信息。需要独立上下文时按 [上下文与交接](references/browser-workflow.md#上下文与交接) 处理，同一画布只有一个操作者。
- 简单读取也反复出现固定长延迟时，按 [固定长延迟的定位](references/browser-workflow.md#固定长延迟的定位) 区分调用链路与实际生成耗时，不重传或重复提交来试速度。

## 交付

默认下载本次结果原片、核验实际文件并在 Codex 展示，同时交付画布链接、节点名称、实际型号与参数；用户要求仅网页交付或任务仅做配置时跳过下载。按 [原片下载与对比](references/browser-workflow.md#原片下载与对比) 区分预览与原片、设置值与媒体规格；无音频开关或播放器静音不能证明没有音轨。下载或展示失败只恢复对应环节，不重新生成，并明确未完成项。未见账单时不把报价或余额变化报告为精确扣费。

## 自改进与异常暂存

页面小幅变化时暂停当前短流程，检查选择、遮挡、网络与控件差异；疑似产品变化时再对照 [官方更新日志](https://docs.tapnow.ai/en/docs/changelog)，日志未提及不代表页面未变。经一次局部 DOM／视觉学习、最小脚本修补和无生成验证后继续。影响输入角色、结果、费用或流程的大幅变化须请用户决定，不静默猜测。保留可回退版本，不在失败时自动发布更新。

开始任务时按[运行约定](references/script-runtime.md#本地诊断日志)启动本地日志维护。脚本自动记录异常、回退和准备超时，纯 MCP／手工流程仅在异常时补记。排障先看近期日志，有复用价值且已核验的结论再按[异常暂存流程](references/self-improvement-log.md)去重归纳。正常成功不记日志，不为积累经验增加测试、费用或授权范围，不自动修改全局配置、记忆或提交推送。
