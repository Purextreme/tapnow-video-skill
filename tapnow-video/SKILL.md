# TapNow 图片、视频与画布操作

本技能用于 Codex；Agent 指 TapNow 网页内置助手，子代理指 Codex 子代理。

## 入口与资料

- 优先复用已连接的官方 MCP，按实时工具参数判断能力；项目、素材和结果查询优先走 MCP。精确型号、首尾帧、分辨率或节点编辑未被覆盖时，用浏览器补足。仅需新增或排查连接时读取 [连接方案](references/connection-options.md)。生成工具可能直接付费提交，不能用来创建测试草稿。
- 页面操作建议优先使用已连接的外部浏览器（如 Chrome），保持稳定且足够大的窗口；用户指定其他浏览器时按指定执行。窗口或缩放变化后重新读取控件位置。未登录时请用户完成一次登录后复用，不读取凭据、令牌或应用隐藏状态，不猜私有 API。
- 需要选择或区分型号时读取 [模型对照](references/models.md)；实际可选模式、参数与费用以当前节点和工具参数为准。
- 上传、节点配置、查询、恢复和下载按 [浏览器工作流](references/browser-workflow.md) 的相关段落执行，不默认加载全部资料。

## 配置与提交

1. 定位原画布、素材和节点，明确每个输入的用途与首尾帧顺序。完整匹配用户指定型号，保留 Omni、Fast、Mini、Pro、Edit 等后缀；MCP 的档位名称不等于具体型号，提示词不能替代实际参数。
2. 先绑定输入，再配置画质、画幅、时长、音频、数量等参数。更换型号、模式或素材后重新核对；检查实际槽位和缩略图，不能只凭 Frames、Auto 或菜单徽标判断配置。
3. 使用页面 Agent 建任务前确认处于 Ask／手动确认模式，无法确认时直接操作画布。核对确认卡及实际节点；Agent 对型号或能力的解释不能代替页面证据。
4. 提交前核对型号、提示词、输入角色、参数、数量、报价和授权预算；首尾帧任务还须通过下方“近固定镜头首尾帧：幻化风险审核”，触发时先暂停并取得风险确认。仅配置或定位测试停在提交前；配置辅助函数不包含 Generate、Confirm 或 Agent Send。
5. 每个任务只提交一次。状态未知时先查原节点和任务，不重复点击或换入口提交；排队和运行中继续查询，明确失败后才按授权判断重试。分批确认及费用见 [批量确认与费用](references/browser-workflow.md#批量确认与费用)。

## 近固定镜头首尾帧：幻化风险审核

- **适用范围**：实际以两张图约束视频首尾状态的任务，不限于命令或模式名称；仅外观参考、单首帧生成不套用本项。准备素材时先审核，最终提交前复核；批量任务逐对检查。
- **视觉检查**：查看实际首尾图，结合用户要求区分预期动画与本应保持不变的区域。比较机位、视角、构图和景别；主体发生动作不等于镜头发生变化。重点对照静止区域中的小物件、纹理、文字、线条、数量、位置、形状及光影，不把这些意外差异解释为所需动画。
- **触发条件**：首尾明显属于固定机位、轻微运镜或构图非常接近，且背景或其他非动画区域有丰富细节、需要保持一致时，必须暂停视频提交并提醒可能出现幻化；发现细节差异时指出具体位置，即使暂未看出差异，也不能据此保证一致或跳过提醒。这是风险判断，不断言一定失败或认定唯一原因。
- **纯净画面例外**：背景确实为白底、纯色或同样缺少细节的干净背景，且其余应静止区域没有明显细节差异或需要精确保留的复杂细节时，可免于本项暂停。不能只凭“白底”二字豁免：若主体的文字、纹理、细小部件或阴影在非预期变化处不一致，仍须提醒。
- **暂停与确认**：简要说明本次触发依据，以及静止细节可能扭曲、溶解或漂移的风险；可提出改用单首帧驱动，或从同一底图局部编辑尾帧、保持非动画区域一致等选项，但不承诺消除风险，也不擅自改方案。等待用户明确选择继续当前首尾帧方案或调整方案后再提交；一般生成指令、费用授权及提示词里的“保持一致”不能代替此次风险确认。用户已知悉并明确接受同一对素材、同一方案的该风险时不重复询问；更换素材或方案后重新审核。
- **证据不足**：图片不可读或缩略图不足以判断细节时，先获取可检查的实际图像，不宣称审核通过或符合纯净画面例外；仍无法检查时说明限制，等待用户决定是否在未完成审核的情况下继续。

## 执行与验证

- 菜单和参数优先 AX／DOM，素材身份、连线和成片效果保留视觉检查。将已确认的连续动作与组末核验合并调用；界面变化或目标有歧义时重新观察。浮动参数入口按 [稳定打开方式](references/browser-workflow.md#浮动参数入口的稳定打开方式) 使用键盘激活。重复定位可用 [节点搜索脚本](references/browser-workflow.md#分组执行与节点搜索)，遮挡按 [画布视图与节点避让](references/browser-workflow.md#画布视图与节点避让) 处理；语义定位不足时再读 [OCR 定位与点击闭环](references/browser-workflow.md#ocr-定位与点击闭环)。
- 提交成功不等于生成完成。按 [生成、查询与网页验收](references/browser-workflow.md#生成查询与网页验收) 核对原任务、实际媒体及播放状态；恢复时沿用原画布和节点。选错型号应如实报告并保留结果。
- 长任务只返回必要字段和图像，在安全阶段保留最小续接信息。需要独立上下文时按 [上下文与交接](references/browser-workflow.md#上下文与交接) 处理，同一画布只有一个操作者。

## 交付

默认下载本次结果原片、核验实际文件并在 Codex 展示，同时交付画布链接、节点名称、实际型号与参数；用户要求仅网页交付或任务仅做配置时跳过下载。按 [原片下载与对比](references/browser-workflow.md#原片下载与对比) 区分预览与原片、设置值与媒体规格；无音频开关或播放器静音不能证明没有音轨。下载或展示失败只恢复对应环节，不重新生成，并明确未完成项。未见账单时不把报价或余额变化报告为精确扣费。

## 自改进与异常暂存

沿用已授权的 [异常暂存流程](references/self-improvement-log.md)：新异常脱敏记录、同类去重，正常成功不记日志；未验证建议不作为正式规则。只处理当前任务必需的恢复，不为积累经验增加测试、费用或授权范围。维护时验证后合并，并校验 Skill；不自动修改全局配置、记忆或提交推送。
