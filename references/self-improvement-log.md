# 自改进异常日志

此文件暂存实际使用中发现的新异常，供后续维护时集中验证、合并；不是已验证操作指南。执行规则与授权边界见 [SKILL.md](../SKILL.md#自改进与异常暂存)。常规操作不默认加载全文，遇到异常只查相关项。

同类异常更新原条目，不重复登记；事实、猜测、已验证恢复方法分别写明。仅保留必要且脱敏的信息，不记录账号、凭据、私有画布地址、项目／节点标识、素材或完整工具输出。未验证的建议不能直接用于替换正式流程。

同步安装副本与来源仓库时，先合并双方新增记录并去重，再核对一致；不能直接覆盖另一份日志而丢失尚未整理的条目。

## 记录格式

新增时使用下列字段；日期和复现次数据实际填写，不以模板内容充当真实异常。

```text
### 日期 — 问题简述
- 状态：待验证／已验证待合并／已合并／不采纳
- 首次与最近发现日期、出现次数：
- 触发条件及必要环境信息：
- 预期与实际表现、影响：
- 本次恢复方法及实际结果：
- 原因猜测／候选改进（未验证）：
- 后续验证方法及结果：
- 合并位置或不采纳原因：
```

## 异常记录

暂无新增条目。已有正式流程中的已解决问题不重复回填；首次新增时替换本行。验证通过后记录合并位置与适用边界，未验证项继续保留待验证；不自动启动后台整理或额外付费测试。
